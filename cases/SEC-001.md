# 06｜SEC-001 Windows 遠端控制工具驗收

## 真實案例狀態：UNKNOWN／待蒐證
使用者提供：AnyDesk、UltraViewer 已停用但仍保留。曾提及 Defender 警示，未取得原始名稱、時間、路徑、處理狀態、完整掃描及連線證據。
這些是使用者陳述，尚非本系統實測結果。本次沒有連接使用者 Windows，也未執行解除安裝或掃描。

## 任務規格
目標：判斷遠端工具是否仍可持續存取、警示是否處理、是否有未釐清入侵線索。
範圍：使用者指定Windows端點；初始A0／A1。禁止刪除、停用防護、放行檔案、上傳可疑檔案到第三方。
資產擁有人、端點ID與日誌調查期間：正式執行前由企業填入。未填則不執行。

| VAC | 具體工作 | 產物 |
|---|---|---|
| 01 | 確認OS、兩套工具來源、版本與路徑 | 清冊 |
| 02 | 讀取Defender狀態及歷史、程序、服務、啟動、排程、帳號、連線 | 有時間戳的原始證據；權限錯誤分開 |
| 03 | 核對威脅分類、檔案簽章與雜湊；辨識良性管理用途 | 偵測表 |
| 04 | 關聯安裝、遠端連線、登入及授權紀錄 | 時間線、事實／推論／未知 |
| 05 | 決定保留受管、解除安裝、隔離或升級調查 | 個別工具處置提案 |
| 06 | 僅依新核准內容執行；本次不執行 | 變更收據 |
| 07 | 重查持續存取、威脅狀態、掃描完成與業務功能 | 六項驗收 |
| 08 | 紀錄決策、責任人、未結案項目與後續追蹤 | 驗收報告 |

## Windows 唯讀查詢起點
以下是人工核對命令，不是已驗證的一鍵蒐證器；需在授權Windows環境確認模組與權限。不要為了執行而關閉防護或更改執行政策。
```powershell
Get-MpComputerStatus
Get-MpThreatDetection
Get-Process | Where-Object { $_.ProcessName -match 'AnyDesk|UltraViewer' }
Get-Service | Where-Object { $_.Name -match 'AnyDesk|UltraViewer' -or $_.DisplayName -match 'AnyDesk|UltraViewer' }
```
歷史偵測不等於目前仍有活躍威脅；名稱篩選可能漏掉改名程式。尚須依程序路徑、簽章、服務ImagePath與企業管理工具蒐證。沒有權限、工具不可用或空結果均分開記錄，不輸出PASS。

## 六項驗收
| 項目 | PASS條件 | 目前 |
|---|---|---|
| 程序 | 無未授權遠端程序；路徑與簽章已核對 | 未驗證 |
| 持續啟動 | 服務、開機啟動、排程與無人值守設定均已查核 | 未驗證 |
| Defender | 防護健康，掃描完成，無未處理威脅 | 未驗證 |
| 身分 | 管理員群組、遠端帳號、工作階段已調查 | 未驗證 |
| 事件 | 約定期間的可疑登入／連線有可追溯結論 | 未驗證 |
| 業務與復原 | 必需功能正常，處置可回復或已接受限制 | 未驗證 |

未保留的歷史不能由現在的掃描補證。若確認未授權控制或憑證外洩，啟動身分撤銷、可信設備輪替及必要重建評估；不能只移除兩款軟體結案。全部PASS表示約定範圍的驗收完成，不保證絕對無入侵。

## 已填合成案例（教學用）
SIM-SEC-001：一台非關鍵測試機，兩套工具停止，但缺少歷史登入紀錄；Defender資料收集失敗。VAC01清冊完成，02收集部分失敗，03無法判定警示，04列缺口，05決策UNKNOWN，06不寫入，07UNKNOWN，08建立補件任務。擁有人：測試IT角色；期限：下一個測試週期。
預期：不得把「程序沒執行」轉成「安全通過」。此案例用於離線決策與缺件處理驗證，不代表真實Windows結果。
