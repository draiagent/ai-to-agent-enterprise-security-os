# 05｜企業導入分階段路線

採驗收門檻推進，不以日曆時間宣告成熟。以下數值是試行提案，企業負責人應依業務確認後凍結，並非業界通用標準。

| 階段 | 落地範圍與工作 | 出場證據 | 負責人 |
|---|---|---|---|
| P1 可觀察 | 選定一組測試端點；盤點擁有人、身分、日誌與備份 | 試行資產100%有責任人；必填欄位完整；斷線有告警；缺證據顯示UNKNOWN | IT資產負責人 |
| P2 可判斷 | 唯讀關聯與影子運作；人工對照結果 | 已標記良性／異常資料集；誤報漏報表；所有高風險測試均升級 | 資安負責人 |
| P3 可行動 | 僅一種經核准、可逆動作；一台非關鍵資產試行 | 越權、過期、急停、重放、回復、業務探針測試通過 | 業務擁有人＋資安主管 |
| P4 持續治理 | 逐項擴展雲端、SaaS、供應鏈與Agent；輪值運維 | 還原演練、成本與效果趨勢、政策版本紀錄、值班交接 | 企業治理負責人 |

## 第一個部署切片
先串 Windows 狀態與事件，完成 SEC-001 唯讀報告。下一切片只增加單一可逆防禦 runbook。每新增資產類型或寫入動作，都重新經過 P1–P3，不因一台測試機通過就全企業上線。

## 量測
- 覆蓋率＝已接入且資料健康的在管資產／核准範圍全部資產；未知資產另列。
- 誤報率＝FP／(FP＋TN)，漏報率＝FN／(FN＋TP)；只有有標記真值資料才計算，分母為0標不適用。
- MTTD、處置及復原時間採同一時間定義與事件範圍，報中位數及P95，不能以少量示範宣稱效能。
- 授權違規測試必須全部阻擋；生產觀察「沒發生」不等於測試通過。
- 成本＝模型／工具／儲存費＋人工時間成本＋維運與變更成本；停機影響另列。沒有實際帳單則標估計。

## 值班與責任
Agent負責例行處理；資安負責人判定事件嚴重性與升級；IT執行環境接入及回復；業務擁有人驗收服務；企業管理者接受殘餘風險。每個角色必須填實際人員與代理人。連續監控需要常駐 Runtime、排程、告警通道及輪值配置，本文件及一次聊天不會自動提供背景監控。

## 升級／回退
出現未授權變更、無法取回證據、錯誤隔離關鍵服務、急停失效時立即停止新增自動變更、撤銷相關能力並回到P2。經根因分析、回歸驗證及責任人同意後恢復。
