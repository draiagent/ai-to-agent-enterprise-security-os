# 自主授權與決策規則

## 五級自主性
| 等級 | 範圍 | 自主條件 |
|---|---|---|
| A0 | 唯讀盤點與收集 | 已核准資料、資產、期間；遵守個資存取範圍 |
| A1 | 關聯分析與報告 | 不改變系統，不對外傳送敏感證據 |
| A2 | 限定防禦，如短效封鎖已驗證惡意指標 | 已測試 runbook、allowlist、可回復、低業務衝擊 |
| A3 | 端點隔離、限定帳號／工作階段處置 | 依資產與事件的預授權條款；缺條款則 REVIEW |
| A4 | 核心帳號、全網隔離、正式資料還原等 | 人工明確核准精確變更，雙人覆核及獨立驗證 |

隔離、停用帳號或封鎖 IP 並非天然低風險；須檢查共用出口、服務帳號與相依業務。正式關鍵系統採較嚴格條件。破壞性清除另行核准且保留證據。

## 決策優先序
1. 急停、範圍不符、撤銷、過期、未列工具／動作、違反禁止事項：DENY。
2. 必要欄位、證據、政策服務或資產身分不完整：UNKNOWN，停止變更並補件。
3. 高影響、不可逆、超出預授權或需要雙人覆核：REVIEW。
4. 所有條件符合且執行前再次通過：ALLOW。

模型不能簽發自己的授權。信心分數不得獨立觸發變更。人批准也不能覆寫企業法規與強制禁止條款。

## 預授權契約
principal、tenant、asset_ids、action_names、allowed_parameters、工具版本、政策版本、valid_from、expires_at、max_targets、速率／重試／預算上限、證據新鮮度、回復程序、驗證方式與核准身分全部綁定。
能力擴張（新增 MCP、Skill、外部網路、子 Agent）視為新變更；不繼承原任務的廣泛權限。
委派權限為父任務授權與子角色政策交集；到期時間不得超過父任務，撤銷向下傳播。

## 緊急處置
事先建立 narrowly scoped 的緊急隔離條款，含觸發證據、對象資產、最大影響與時間。沒有條款時由值班人員決策；不能用「緊急」繞過政策。急停須可由模型外通道操作；復工先人工檢查事件、未完成操作及授權。

## 回復
變更前保存可用的設定快照；確認管理回路不被自己隔離。回復會重新開放暴露面時須再次評估，不能盲目自動回復。隔離解除前完成乾淨性檢查與業務測試。不可逆操作標明沒有技術回復，不使用「可回復」掩蓋資料損失。
